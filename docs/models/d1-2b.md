# ⚡ d1-2B — the tiny decision model

> **TL;DR**
>
> | | |
> |---|---|
> | On disk | 1.85 GB (`Q8_0`) |
> | Where it lives | entirely on the GPU (2.6 GB VRAM) |
> | Answers | a probability for each allowed answer, no generated text |
> | Latency | 27–31 ms a decision |
> | Grading pibench | 80% accuracy, below the 81% baseline, 0.3 s a transcript |
> | Command guard | 4/10 scary-but-safe right, 1/20 dangerous let through, 31 ms |
> | [Security audit](../security.md) | clean |
> | Launch | `QMODEL=d1 bash scripts/run-qwen.sh` |

## What is it?

[LiquidAI's decision model](https://huggingface.co/LiquidAI/d1-2B-GGUF), served through the same
`/v1/systemone` endpoint as [Clef-Flash](clef-flash.md), and small enough to sit next to another model
on the GPU. It's a fast router and a nervous guard: it balks at `rm -rf ./build`, and even at
`git stash && git checkout`.

## Install & run

```bash
bash scripts/download-models.sh d1
QMODEL=d1 bash scripts/run-qwen.sh     # server on port 8080, -c 8192 -ub 4096
```

The request is the same as [Clef-Flash's](clef-flash.md#install--run). `bash bench/smoke/run.sh d1` is the
quick check.

## Our numbers

| Test | d1-2B | Clef-Flash |
|---|---:|---:|
| Smoke test, 12 labelled requests | 12/12, 27 ms | 12/12, 183 ms |
| Grading 252 pibench attempts | 80%, 17/189 false alarms | 86%, 4/189 false alarms |
| Command guard, dangerous let through | 1/20 | 1/20 |
| Command guard, scary but safe | 4/10 | 8/10 |

The full tables and the method are on [Clef-Flash's page](clef-flash.md#our-numbers).

## Gotchas

- Good for routing clear requests. For grading pibench it doesn't beat "solved unless it timed out".
- `-ub` must cover the longest input, as with Clef-Flash.
