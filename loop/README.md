# The lab notebook

These are the commands as they really ran overnight, and `STATE.md` is the journal: what happened, in order,
wrong turns included. Some queues failed on a bad flag and were rerun under a new number.

**To repeat a result, use [docs/reproduce.md](../docs/reproduce.md).** It has the cleaned-up commands;
nothing here is meant to be run again. `gpu.sh` runs one job in its own scope, with its log in the
git-ignored `logs/`.
